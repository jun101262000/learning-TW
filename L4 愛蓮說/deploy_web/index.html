👤 作者與題解檔案 ‧ 周敦頤
學習區

📜 作者檔案：濂溪先生 周敦頤

朝代時代：北宋（西元 1017 ~ 1073 年，年五十七）

字號籍貫：字茂叔，號濂溪，道州營道（今湖南省道縣）人。

文學地位：北宋著名的理學家、哲學家，被尊為「理學開山祖師」，黃庭堅稱讚其「胸懷灑落，如光風霽月」。

高尚節操：為官清廉公正、明察秋毫平反冤獄。窗前雜草欣欣向榮而不除，以體會天地好生之德；病重時家當僅一舊箱，內無百錢，兩袖清風。

🌸 題解與寫作手法

本文選自《周元公集》。「說」是一種古代解析事理、闡述己見的論說文體。作者藉蓮花「出淤泥而不染」的特質象徵君子美德，以菊花為正襯、以牡丹為反襯，全篇不到一百二十字，融記敘、描寫、議論與抒情於一體，立意深遠，發人深省。

🔍 4. 詞語二 ‧ 多音字與重要詞語延伸
學習區

🎯 一字多音深入辨析：

鮮（ㄒㄧㄢˇ / ㄒㄧㄢ）

• ㄒㄧㄢˇ（少、罕見）：陶後鮮有聞、鮮為人知、寡廉鮮恥。
• ㄒㄧㄢ（新鮮、鮮美）：鮮花、鮮豔奪目、海鮮、屢見不鮮。

盛（ㄕㄥˋ / ㄔㄥˊ）

• ㄕㄥˋ（興旺、熱烈、極度）：世人盛愛牡丹、盛況空前、繁盛、盛情。
• ㄔㄥˊ（用器具裝受、容納）：盛裝食物、盛飯、盛水。

說（ㄕㄨㄛ / ㄕㄨㄟˋ / ㄩㄝˋ）

• ㄕㄨㄛ（言論、文體）：愛蓮說（古代論說文體）、說明、言說。
• ㄕㄨㄟˋ（勸說使從）：遊說諸侯。
• ㄩㄝˋ（通「悅」）：學而時習之，不亦說乎。

遠（ㄩㄢˇ / ㄩㄢˋ）

• ㄩㄢˇ（距離長、高遠）：香遠益清、可遠觀、任重道遠、遠方。
• ㄩㄢˋ（避開、疏遠）：親賢臣，遠小人（動詞用法）。

🌟 課文重點成語與詞義拓展：

出淤泥而不染

比喻處於不良環境中，依然能保有純潔剛正的品德，不隨波逐流。

不蔓不枝

比喻品德正直坦蕩，不拉幫結派、不攀附權貴；文章亦可形容簡練流暢、無贅語。

亭亭淨植

形容姿態高潔挺拔，令人產生莊嚴敬畏之心，不容輕率慢侮。

💡 5. 解釋 ‧ 核心詞彙與文句釋義
學習區
出淤泥而不染

淤泥，水底沉積的爛泥。比喻君子生於濁世，依然潔身自愛、不同流合汙。

濯清漣而不妖

濯，洗滌；清漣，清水波紋。象徵君子節操高雅端莊，不媚世阿俗。

中通外直，不蔓不枝

花梗中空挺直，不蔓生細莖與旁枝。象徵君子胸懷坦蕩、行為正直，不攀附權貴。

香遠益清，亭亭淨植

香氣越遠越清雅，高挺潔淨直立。象徵君子美德芳名遠播、人格獨立純潔。

可遠觀而不可褻玩焉

褻玩，輕慢玩弄。象徵君子高尚品格令人心生敬佩，不敢輕慢侮弄。

宜乎眾矣

宜乎，應當。表面陳述愛牡丹者多，實則委婉批評世俗多爭名逐利。

🔤 6. 相似字 ‧ 形似字互動辨析與練習
學習區

點擊發音按鈕聆聽相似字差異，並在下方挑戰互動選字小試身手：

淤 vs 瘀（音 ㄩ）
• 淤（氵部，11畫）：池底沉積的爛泥。
 例：出淤泥而不染、泥沙淤積、淤塞。
• 瘀（疒部，13畫）：血液凝聚不通。
 例：瘀血紅腫、內傷瘀斑。
濯 vs 擢 vs 耀 vs 躍
• 濯（ㄓㄨㄛˊ，氵部）：洗滌。例：濯清漣而不妖、童山濯濯。
• 擢（ㄓㄨㄛˊ，扌部）：拔升。例：拔擢人才、擢升。
• 耀（ㄧㄠˋ，羽部）：照耀、顯揚。例：光耀門楣、炫耀。
• 躍（ㄩㄝˋ，足部）：跳動。例：雀躍不已、躍躍欲試。
蔓 vs 漫 vs 謾（音 ㄇㄢˋ）
• 蔓（艸部）：植物細莖。例：不蔓不枝、順藤摸蔓。
• 漫（氵部）：放縱無拘、水滿溢。例：漫山遍野、漫不經心。
• 謾（言部）：欺謾、辱罵。例：謾罵、欺謾。
褻 vs 藝 vs 毅
• 褻（ㄒㄧㄝˋ，衣部）：輕慢侮弄。例：不可褻玩、褻瀆神明。
• 藝（ㄧˋ，艸部）：才藝技能。例：文藝創作、十八般武藝。
• 毅（ㄧˋ，殳部）：剛強堅決。例：剛毅木訥、毅力堅定。

⏳ 8. 課文順序 ‧ 愛蓮說論證結構脈絡
學習區
第一步：總起概說

「水陸草木之花，可愛者甚蕃。」以眾多花卉引出每個人各有所好的世態背景。

第二步：烘托對比

「晉陶淵明獨愛菊，自李唐來世人盛愛牡丹。」以菊為正襯、牡丹為反襯，烘托作者自己「獨愛蓮」。

第三步：描摹蓮德

「出淤泥而不染...可遠觀而不可褻玩焉。」透過蓮花的生長環境、外觀、氣味與姿態，象徵君子的純潔、正直、通達與崇高。

第四步：言志慨嘆

「菊之愛陶後鮮有聞，蓮之愛同予者何人？牡丹之愛宜乎眾矣！」感嘆守德君子罕見，流俗逐利者眾多，寄寓深刻人生期許。
