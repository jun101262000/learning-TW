# 琦君〈下雨天，真好〉數位教材系統

本專案為國民中學語文領域教學設計之數位適性教材系統。
提供課文有聲點讀、情境插圖、字詞鷹架習寫、注釋探索、圖文配對、情節排序、綜合會考與 A4 紙本學習單即時生成。

## 🚀 GitHub Pages 部署步驟

1. 將本資料夾（`deploy_web`）內的所有檔案（包含 `index.html`、`assets/`、`.nojekyll` 等）上傳或推送（push）至您的 GitHub 儲存庫（Repository）。
2. 在 GitHub 該儲存庫頁面，點選頂部 **Settings** ➔ 左側選單 **Pages**。
3. 在 **Build and deployment** 下方的 **Branch**：
   - 選擇 `main`（或 `master`）分支
   - 資料夾選擇 `/(root)`
   - 點擊 **Save**。
4. 等待 1~2 分鐘後重新整理頁面，即可看到綠色的發布網址（例如：`https://<你的帳號>.github.io/<儲存庫名稱>/`）！

## 📊 Google 試算表即時作答同步設定

1. 教師開啟 Google 試算表（或建立新表）。
2. 點選頂端選單 **擴充功能 (Extensions)** ➔ **Apps Script**。
3. 貼上系統內建之 Webhook Apps Script 程式碼（可於教材右上角「📊 雲端試算表設定」中一鍵複製）。
4. 點擊右上角 **部署 (Deploy)** ➔ **新增部署作業 (New deployment)**：
   - 種類選「網頁應用程式 (Web app)」
   - 誰可以存取 (Who has access) 選擇 **「任何人 (Anyone)」**
   - 複製取得的 Web App 網址。
5. 於教材網頁右上角「📊 雲端試算表設定」貼上網址並儲存，全班學生（座號 01-06）之作答成果、耗時與學習診斷即自動即時同步寫入該試算表！
