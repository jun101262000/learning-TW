( B　 ) 1. 有關《世說新語》一書的說明，下列敘述何者錯誤？
(A) 屬於筆記小說，是中國志人小說的傑出代表作品
(B) 由南朝宋劉義慶編撰，依時代編年分類，屬於嚴謹的歷史小說
(C) 全書共三十六篇，記載東漢至東晉間高士名流的軼聞瑣事
(D) 文字簡潔精鍊，刻劃人物形象栩栩如生，對後世小說影響深遠
💡 解析：《世說新語》由劉義慶召集文人編撰，按人物品評主題分類為三十六篇（如德行、言語、雅量、忿狷等），並非依時代編年分類，性質為志人筆記小說而非正式歷史小說。
( C　 ) 2. 郗太尉聽了門生對王家諸郎的觀察後，由他的回答與抉擇，可看出他欣賞王羲之何種特質？
(A) 飽讀詩書，文章滿腹，才華冠絕當世
(B) 體格強健，坦腹耐寒，適應力極佳
(C) 本性率真灑脫，毫不矯揉做作，具真名士雅量
(D) 孤芳自賞，冷淡傲慢，不與凡俗同流
💡 解析：王家眾子弟聽聞挑婿皆刻意拘謹端莊（咸自矜持），唯獨王羲之在東床上坦腹仰臥若無其事，展現不拘世俗禮法的真性情，深獲郗太尉激賞。
( A　 ) 3. 在〈坦腹東床〉一文中，王丞相對使者說「君往東廂，任意選之」，這句話反映出王丞相具有何種心態？
(A) 對自家子弟素質深具自信，態度寬厚大方
(B) 對郗太尉之提親感到敷衍冷漠，不願過問
(C) 認為自己家族高高在上，看不起求親之人
(D) 自知子弟平庸無奇，任憑對方碰碰運氣
💡 解析：王導身為當朝首輔名門望族，開放東廂任由使者自選，展現出對子姪才學氣度的高度自信與門閥世家的大度風範。
( D　 ) 4. 王羲之聽到王藍田吃雞蛋的事大笑說：「使安期有此性，猶當無一豪可論，況藍田耶？」這段話透露出什麼訊息？
(A) 讚美王安期虎父無犬子，家風強悍
(B) 肯定王安期平素教子有方、循循善誘
(C) 譏諷安期父子二人皆性急魯莽、不可理喻
(D) 認為王安期比王藍田穩重許多，藍田遠不及乃父
💡 解析：王羲之以其父王安期的寬厚穩重反襯王藍田的急躁幼稚，指出若是名望崇高的父親有這種急性子都一無可取，更何況是資望尚淺的藍田。
( C　 ) 5. 〈王藍田食雞子〉文中連續運用許多動詞刻劃人物。依據故事發展，下列動詞出現的先後順序何者正確？
(A) 刺 ➔ 食 ➔ 蹍 ➔ 擲 ➔ 齧 ➔ 取 ➔ 吐
(B) 食 ➔ 擲 ➔ 刺 ➔ 取 ➔ 蹍 ➔ 吐 ➔ 齧
(C) 食 ➔ 刺 ➔ 擲 ➔ 蹍 ➔ 取 ➔ 齧 ➔ 吐
(D) 刺 ➔ 擲 ➔ 食 ➔ 蹍 ➔ 齧 ➔ 取 ➔ 吐
💡 解析：課文敘述：嘗「食」雞子 ➔ 以筯「刺」之 ➔ 舉以「擲」地 ➔ 屐齒「蹍」之 ➔ 復於地「取」內口中 ➔ 「齧」破 ➔ 即「吐」之。
( B　 ) 6. 「雞子於地圓轉未止，仍下地以屐齒蹍之，又不得，瞋甚。」依據此段文字，下列敘述何者正確？
(A) 由「以筯刺之」可推知王藍田手腕有力且武藝超群
(B) 由「舉以擲地」可推知王藍田因久刺不中而勃然大怒
(C) 由「仍下地以屐齒蹍之」可推知其處事審慎周延、步步為營
(D) 由「齧破即吐之」可推知其怒氣已消、情緒逐漸平穩
💡 解析：刺不得便大怒舉以擲地，鮮明呈現其性急易怒之心理與舉止。
( D　 ) 7. 「王家諸郎，亦皆可嘉，聞來覓婿，咸自矜持」句中「咸」字的意思與下列何者相同？
(A) 老少「咸」宜之食品
(B) 「咸」陽城外古道邊
(C) 味「鹹」口渴需飲水
(D) 少長「咸」集
💡 解析：「咸自矜持」之「咸」為「都、皆」之意；《蘭亭集序》「少長咸集」之「咸」亦為「都」之意。
( C　 ) 8. 下列文句中的「書」字，何者意思指「信件、書信」？
(A) 家徒四壁，唯有萬卷「書」
(B) 臨池摹寫，其「書」法絕妙
(C) 遣門生與王丞相「書」，求女婿
(D) 「書」不盡言，言不盡意
💡 解析：「與王丞相書」意指寄信給王丞相，此處「書」作名詞信件或動詞寫信解。
( B　 ) 9. 若將〈坦腹東床〉與〈王藍田食雞子〉兩文的主角性格並置比較，下列敘述何者最貼切？
(A) 王羲之虛偽造作，王藍田忠厚老實
(B) 王羲之率真豁達，王藍田暴躁偏激
(C) 王羲之膽小怕事，王藍田勇敢果斷
(D) 王羲之好逸惡勞，王藍田勤奮上進
💡 解析：王羲之展現率真自信與名士雅量，王藍田則為一隻滾動的雞蛋暴跳如雷，形成強烈對比。
( D　 ) 10. 魏晉名士流行服食「五石散」，課文補充教材指出這是一種「古代的危害流行」。下列敘述何者正確？
(A) 五石散確實能延年益壽，令古人體質健碩超凡
(B) 現代人應效法古人文雅，適度服用各種礦物草藥以增靈感
(C) 五石散是當時官方明文規定的全民保健食品
(D) 吃五石散會導致重金屬中毒與躁熱，文人袒胸散步實為發散毒性之無奈之舉
💡 解析：五石散含多種重金屬礦物，服後身體燥熱、神經受損，穿寬袍散步（行散）都是為了散熱防毒發，切不可盲目仿效。
( A　 ) 11. 炎熱的七月七日，富貴人家紛紛將箱中綾羅綢緞與藏書搬出曝晒，郝隆卻赤身躺在太陽底下坦腹。此舉展現郝隆何種形象？
(A) 不隨流俗，以腹中博學自豪
(B) 貪戀日光，沉迷戶外運動
(C) 家境貧寒，無物可晒而羞憤
(D) 精神錯亂，行為舉止怪誕
💡 解析：郝隆坦腹晒肚皮，自嘲「晒我腹中之書」，既諷刺富人炫富，亦顯其不拘世俗之狂狷。
( C　 ) 12. 王戎家境十分富有，但賣李子時總怕別人得到優良品種，所以事先將李核一顆顆鑽破。此事反映出王戎何種形象特色？
(A) 聰慧機靈，防患未然
(B) 眼光獨特，精研園藝
(C) 吝嗇小氣，錙銖必較
(D) 豁達大度，樂善好施
💡 解析：賣李鑽核是《世說新語．儉嗇》篇的著名典故，極傳神地描繪其小氣吝嗇的性格。
( D　 ) 13. 當朝宰相王導權傾天下，每當王導發表言論，在座賓客皆爭相稱讚附和，唯有王藍田不為所動，不隨便附和。這反映王藍田何種特質？
(A) 目中無人，故意與權貴作對
(B) 反應遲鈍，聽不懂眾人言論
(C) 城府深沉，伺機搶奪宰相位
(D) 不隨聲附和，保有獨立剛正性格
💡 解析：王藍田雖性急，但在政治場合不隨聲附和，展現其正直剛強、不盲從權勢的一面。
( B　 ) 14. 孔融隨父訪李膺，座上陳韙諷刺說「小時了了，大未必佳」，孔融當場回敬「想君小時，必當了了」。此舉展現孔融何種特質？
(A) 目無尊長，口出惡言無教養
(B) 聰慧機靈，思維敏捷反應迅疾
(C) 懦弱怕事，只能暗自垂淚
(D) 心胸狹隘，容不得半點規勸
💡 解析：孔融以子之矛攻子之盾，既反擊陳韙對自己的否定，又暗諷陳韙如今平凡，機敏過人。
( A　 ) 15. 「東床快婿」一詞的典故出自王羲之，其同義詞下列何者正確？
(A) 乘龍快婿
(B) 入幕之賓
(C) 金屋藏嬌
(D) 南柯一夢
💡 解析：「東床快婿」與「乘龍快婿」皆用以稱讚優秀的女婿。
( A　 ) 16. 「王家諸郎……咸自矜持；唯有一郎，在東床上坦腹臥」這段描寫運用了何種修辭手法？
(A) 映襯（對比）
(B) 譬喻
(C) 排比
(D) 借代
💡 解析：以王家其他子弟的「咸自矜持」與王羲之的「坦腹臥」並列，形成鮮明強烈的對比映襯。
( B　 ) 17. 「復於地取『內』口中，齧破即吐之」句中的「內」字，其字義與讀音下列何者正確？
(A) 讀作ㄋㄟˋ，指房門內部
(B) 讀作ㄋㄚˋ，通「納」，放入之意
(C) 讀作ㄋㄚˋ，指衣服的內襯
(D) 讀作ㄋㄟˋ，同「訥」，說話遲鈍
💡 解析：此處「內」為古字通假，通「納」，讀音ㄋㄚˋ，動詞，收納、放進之意。
( A　 ) 18. 下列文句中「語」字的讀音，何者與其他三者不同？
(A) 丞相「語」郗信（告訴）
(B) 默默無「語」
(C) 「語」言文字
(D) 自言自「語」
💡 解析：A項動詞「告訴」讀作ㄩˋ；其餘三項名詞或副詞「言語」讀作ㄩˇ。

(A) 記載了皇宮內院龐大的軍事爭戰紀錄
(B) 全書文字晦澀艱深，充滿神祕道教咒語
(C) 以簡鍊傳神的筆墨生動呈現人物性格與名士風神
(D) 由朝廷皇帝親筆撰寫，規定為科舉考試必考範本
💡 解析：《世說新語》善用寥寥數語刻劃人物性格與神采，是中國筆記小說與人物美學的最高代表。
( D　 ) 20. 讀完〈王藍田食雞子〉的故事，我們在日常生活與人際相處中最應汲取的借鏡為何？
(A) 吃雞蛋時一定要用特製湯匙，不可用筷子
(B) 他人犯錯時應立刻大聲嘲笑，展現幽默感
(C) 凡事爭強好勝，才能博取大眾眼球
(D) 學會情緒管理，遇事莫急躁暴怒，以免失態損己
💡 解析：王藍田因一顆小雞蛋情緒失控、連番醜態百出，啟發我們培養沉穩情商與自控能力。
